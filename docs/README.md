# SURE 文档

SURE 有三层：**判断**（Skill）、**确定性操作**（CLI）、**集成**（MCP）。同一套证据模型，三种使用方式。

第一次来，按这个顺序读：

1. [快速开始](quickstart.md) —— 装一次，用 `sure do` 路由到五类产品。
2. [核心概念](concepts.md) —— 六类结论、证据形式、E0–E5 的适用范围。
3. [五类产品研究包](modes.md) —— 软件/硬件/消费品/汽车/手机的方法地图。
4. [CLI 参考](cli.md) —— 命令、参数、退出码。
5. [数据契约](data-contract.md) —— study/route/normalized/analysis/manifest。
6. [平台与连接器](connectors.md) —— 数据在哪、怎么合规拿、哪些被阻断。
7. [故障排查](troubleshooting.md) —— 装不上、门禁不过、MCP 连不上。
