运行示例研究 学习需求验证方法 带来一个产品决定

通用 Agent 会推理，Askovo 把真实证据带进研究RESEARCH BEYOND THE PROMPT

一份漂亮的研究答案，价值取决于背后的材料。Askovo 帮团队走出已有上下文，继续获得和检验新证据。

采集真实材料汇集社区反馈、访谈材料、竞品记录和授权导出，保留来源、时间与失败状态。
检验需求假设区分概念反馈、原型反馈、付费意愿表达和真实行为；模拟用户不能成为需求证据。
推进并复审决定让支持、反例和未知项跟着主张走，新证据到来时继续复审同一个决定。

从研究执行到需求验证，每一步都回到原始材料FROM EVIDENCE TO VALIDATION

1 · 定义决定从有投入代价的产品选择开始，明确对象、范围和待证伪假设。
2 · 采集与导入使用社区反馈、访谈材料、竞品记录、授权导出，以及概念或原型反馈。
3 · 带着来源分析定量与语义分析都要回到原文、反例和覆盖缺口。
4 · 验证并决定区分口头兴趣、付费意愿和真实行为，由负责人选择下一步并随证据复审。

底层仍是一条清晰的研究链：场景 → 用户 → 痛点 → 需求 → 特性 → 产品 → 商业。它负责把材料连成判断，真正的价值来自材料是否真实、验证是否成立。
