# 0. 摘要：市场侧最重要的六个判断

> 填写指引：6 条左右，每条一句话 + 证据标签。必须包含一条"我们尚无/已有自己的市场"的诚实判断，和一条"用户买的是什么（不是什么）"的翻译判断。

示例（合成）：
1. **我们尚无"自己的市场"**——只有相邻市场付费证据【F】与真实的问题讨论语料【R】；市场存在性 = 待首批付费验证。
2. **用户买的是"判断的改善"，不是____**（技术名词）。

# 1. 市场定义与口径纪律

## 1.1 我们说的"市场"是什么

> 填写指引：三个"不是" + 一个"是"。"不是"指向品类消费总额/技术供给分类，"是"用 人群 × 情境 × 任务 定义，规模待测。

## 1.2 口径纪律（引用数字时的强制要求）

> 填写指引：左列写本项目最容易犯的推断（从 05-audit 的禁止推断与语料偏差来），右列给合法替代表述。每条对应研究层的真实口径。

| 禁止 | 替代 |
| --- | --- |
| "____万亿市场，我们切 1%…" | "____人群中的____的付费意愿待____验证" |
