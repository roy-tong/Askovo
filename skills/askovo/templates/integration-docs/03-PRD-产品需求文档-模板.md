# 2. 数据与算法需求（研发侧头号输入，可选）

> 填写指引：模块表：信号质量/特征/校准/输出/反馈，每行"需求 + 依赖"。两条纪律：产品指标口径从第一天就按对照实验分组记录（避免事后补采）；输出引擎先规则后模型（可解释优先），反馈不做游戏化（引用研究层竞品差评模式）。
