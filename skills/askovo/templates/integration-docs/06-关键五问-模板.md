# 06 · 关键五问：最可能改变产品决策的问题

> 主链版本 · 投影版本。五问来自 `04-findings/product-reasoning.json` 的高影响节点/推导边、04 缺口和 BRD 商业门，不另建结论。
> 每问必须写：chain/node/edge、当前答案、证据与反证、可观察证伪、结果回写位置。优先选择“答案会改变行动 × 当前不确定性高”的问题。

## Q1 场景与用户：我们是否找对了决策上下文？

- **chain/node/edge**：`PR__.scene→user`；
- **当前答案**：____（不知道 / 有方向但未覆盖 / 当前证据支持到____）；
- **证据与反证**：R__；可触达样本、角色推断和无问题场景的限制：____；
- **证伪与动作**：若____，则改 scene/user 或停止该分群；
- **回写**：主链 → MRD → 04 修改日志。

## Q2 痛点与需求：问题是否值得改变，而非只是被谈论？

- **chain/node/edge**：`PR__.user→pain→need`；
- **当前答案**：____；
- **证据与反证**：替代成本、后果、满意替代和不消费案例：____；
- **证伪与动作**：若现有办法足够或后果低于____，则收缩/关闭该 Need；
- **回写**：主链与需求判断，不以讨论频率保留方向。

## Q3 需求到特性：候选特性真是必要回应吗？

- **chain/node/edge**：`PR__.need→feature`；
- **当前答案**：____；
- **证据与备选**：`alternatives_considered` 包括低成本、非产品化和不做：____；
- **证伪与动作**：若简单替代达到____或特性增加负担超过____，则删除/改 Feature；
- **回写**：主链 → PRD，不能只改功能清单。

## Q4 特性到产品与商业：组合形态是否被采纳并可能持续？

- **chain/node/edge**：`PR__.feature→product` + 商业假设；
- **当前答案**：____；
- **证据与反证**：概念接受、真实负担、试点行为、付费/续约及各自边界：____；
- **证伪与动作**：若____，则改 form/scope、收费或停止扩张；
- **回写**：主链、BRD 商业决策和 05 定价投影。

概念接受不是留存，LOI 不是订单，首购不是复购。需求判断 `validated` 不等于产品或商业成功。

## Q5 什么时候知道这条路错了？

- **主链熔断**：哪个 node/edge 的什么反证使 chain 改为 `rejected` 或退回 `hypothesis`；
- **业务 G 门**：G0→G1、G1→G2、G2→扩张各自的通过与不通过动作；
- **安全停点**：独立 HOLD/S0 的监管、伦理、隐私、数据权利或安全条件；
- **决策责任**：谁复审、何时复审、哪些证据必须出现才能重启。

业务 G 门与安全 HOLD/S0 不得混写。chain `decided` 只记录当前产品决策，不能取消熔断和复审。
